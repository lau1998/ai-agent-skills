# Output Formats And Images

## Maintain One Fact Model

Build Markdown, illustrated standalone HTML, and PDF from one shared set of confirmed traveler facts, verified itinerary facts, budget figures, assumptions, and sources. Keep dates, route order, durations, prices, warnings, and citations identical across formats. Update the shared model first when a fact changes.

## Deliver Markdown

Use Markdown as the durable default and include:

1. Confirmed trip summary.
2. Assumptions, currency basis, and verification date.
3. Daily itinerary with transport, buffers, meals, rests, reservations, safety, and fallbacks.
4. Accommodation-area and transport guidance.
5. Categorized budget with `free`, `core paid`, and `optional paid` items.
6. Preparation, packing, weather, health, safety, etiquette, and emergency guidance.
7. Full sources with publishers, direct links, applicable dates, and verification dates.

Keep source traceability in the deliverable or a clearly attached appendix. User pressure cannot remove it.

## Deliver Illustrated HTML

Generate a single standalone, responsive, printable HTML document. Preserve every core fact and source from Markdown. Give each real image a caption, source or rights holder, and link to the original page. Verify that mobile and desktop layouts have no horizontal overflow, text overlap, clipped content, broken navigation, or nonfunctional interactions. Verify print styles and readable source URLs.

Do not use visual polish to obscure uncertainty, omit citations, or compress safety information beyond recognition.

## Deliver PDF

Create a PDF only after the user explicitly requests it and approves the HTML. Render and inspect every page. Check pagination, page breaks, image resolution and captions, working or printed links, table fit, headers and footers, and Chinese font embedding and glyph rendering. If HTML approval is absent or PDF export fails, preserve and deliver the valid Markdown; do not deliver a broken or partially rendered file.

## Source Real Images Responsibly

Prefer official images or clearly licensed reusable real images. Record the publisher or creator, license when provided, and original link. Omit the image when licensing or provenance is unclear. Never imply that a generic or old image proves current hotel rooms, roads, attractions, weather, crowding, or conditions.

## Gate AI Images

Obtain explicit prior consent before any AI image generation. A broad request to make the guide attractive is not consent. If consent is granted:

- Use AI images only for a cover or atmosphere illustration.
- Put the exact phrase `AI 生成示意图` in every AI image caption.
- Put the exact phrase `AI 生成示意图` in every AI image alt text.
- Identify the image as AI-generated again in the image credits or source appendix.
- Never use an AI image as factual evidence for a hotel, road, attraction, weather, transport, or safety condition.
- Refuse requests to disguise AI output as real or remove the disclosure.

If the user declines AI images, use only verified, appropriately licensed real images or omit imagery.
