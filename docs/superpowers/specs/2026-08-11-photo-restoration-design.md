# Photo Restoration Skill 设计

## 目标

新增 `photo-restoration` Skill，用于修复模糊、褪色、受损或低质量的老照片。Skill 默认优先保持原始信息，在用户明确要求时提供现代增强模式。

该 Skill 归入 `other`，因为主要交付物是修复后的位图照片，不是代码或工程配置。

## 参考来源

设计参考 [ShinChven/nano-banana-skills 的 photo-restoration Skill](https://github.com/ShinChven/nano-banana-skills/blob/main/skills/photo-restoration/SKILL.md)。参考项目使用 MIT License。

本项目保留参考方案中的核心目标：修复模糊和老化问题，同时保持人物身份、姿势和构图。实现会重新组织工作流，并适配当前 ImageGen 工具的编辑方式、保存规则和能力边界。

## 文件结构

```text
skills/other/photo-restoration/

└── agents

```

首版不增加脚本、参考文件或图片资源。图像分析、编辑和结果检查直接使用已安装的 `imagegen` Skill 与内置图像工具。

## 触发范围

以下需求应触发该 Skill：

- 修复老照片、旧照片、模糊照片或低质量照片。
- 去除划痕、折痕、污点、噪点或胶片颗粒。
- 恢复褪色、对比度、曝光和轻微失焦。
- 提升照片清晰度，或在明确要求时让老照片呈现现代效果。
- 在明确要求时为黑白照片上色。

仅调整尺寸或格式、抠图、换背景、替换物体等需求不属于该 Skill 的主要职责，应交给通用图像编辑流程。

## 双模式

### 忠实修复

这是默认模式。修复划痕、折痕、污点、噪点、褪色、曝光问题和可恢复的模糊，同时保留下列不变量：

- 人物身份、脸型、五官比例、年龄、表情和视线。
- 发型、姿势、手势、服饰和配饰。
- 人物数量、主体位置、构图、裁切和宽高比。
- 背景、物体、文字、历史环境和年代细节。
- 原始黑白、棕褐色或彩色状态。

默认不磨皮、不美化人物、不改变年代感，不凭空重建无法从照片判断的大面积细节。

### 现代增强

只在用户明确要求“现代化”“上色”“电影感”或类似效果时启用。可增强清晰度、光线、肤色和局部细节，但仍必须保持人物身份、姿势、构图和场景内容。

固定的 85mm、浅景深或电影光效只作为用户明确要求现代摄影风格时的可选提示，不作为每次修复的默认设置。

## 工作流

1. 确认存在编辑目标。对话中没有照片时，请用户上传或提供照片。
2. 如果照片只存在于本地文件系统，先用 `view_image` 加载，使其进入对话图像上下文。
3. 把输入照片标记为编辑目标，而不是仅供风格参考的图片。
4. 检查人物、构图、年代特征和损伤类型，区分可修复缺陷与无法可靠推断的缺失内容。
5. 根据用户要求选择忠实修复或现代增强。没有明确要求时使用忠实修复。
6. 构造 ImageGen 编辑提示，先写修复目标，再逐项写保留不变量和禁止事项。
7. 默认使用内置图像编辑工具。除非用户明确要求 CLI 或模型路径，否则不切换到需要 API Key 的 CLI 流程。
8. 检查输出中的身份、人数、姿势、构图、服饰、背景和年代细节，并与原图比较。
9. 出现身份漂移或内容变化时，只针对该问题进行一次定向重试，不叠加新的美化要求。
10. 默认保存为新文件，不覆盖原照片。报告输出路径、使用模式和主要修复内容。

## 提示结构

提示词应包含：

```text
Use case: identity-preserve 或 precise-object-edit
Primary request: 忠实修复或现代增强的具体目标
Input images: Image 1 是编辑目标
Restoration: 需要处理的损伤、模糊、噪点、曝光或褪色问题
Constraints: 必须保持的人物身份、姿势、服饰、构图、背景和年代细节
Avoid: 新增人物或物体、改脸、改年龄、过度磨皮、改变裁切、文字、水印
```

含人物的照片优先使用 `identity-preserve`；无人照片或以局部损伤修补为主时使用 `precise-object-edit`。

“8K”只能作为高细节视觉目标，不能宣称内置工具实际输出了 8K 像素文件。用户要求精确分辨率时，应说明当前工具支持的实际输出能力。

## 错误处理

- 没有输入照片时不生成替代照片，先请求用户提供编辑目标。
- 照片过度损坏、关键面部或主体区域完全缺失时，说明重建会包含推测，并在继续前确认。
- 用户没有要求上色时，保持原始色彩状态。
- 内置图像工具不可用时，说明 CLI 备用方案及其 API Key 要求，得到用户明确同意后才能切换。
- 结果发生明显身份漂移、人物数量变化或构图变化时，不交付该版本，调整保留约束后重试。
- 不覆盖原文件，除非用户明确要求替换。

## 边界

首版不实现批量修复、确定性传统图像算法、人工蒙版生成、面部识别或独立放大脚本。用户后续提出这些需求时，再为相应能力设计脚本或独立 Skill。
